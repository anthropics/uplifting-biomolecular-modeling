# NOTICE — third-party components used (none redistributed except as noted)

The kit's own code under opt/ is new add-on source (the `mosaic.fast` sub-package in mosaic_fast/, the drivers, tests and documents); licenses/
holds verbatim copies of the upstream licence texts. stock/ redistributes the three upstream projects verbatim at their pins as `git archive`
tarballs (stock/mosaic-70fec525.tar.gz, stock/joltz-ed0f0425.tar.gz, stock/boltz-1acc397b.tar.gz) plus an unpacked excerpt under stock/src/,
each with its upstream LICENSE/NOTICE files inside; no upstream source file is modified. The mosaic archive carries, exactly as committed
upstream, the ProteinMPNN and AbMPNN weight files, a UniRef50-derived data table and an AlphaFold code sub-tree, each under its own terms with
upstream's notice beside it (rows below). The Boltz-2 checkpoints and the CCD molecule library are downloaded by the user and are not
redistributed; the container recipes add no weights beyond what the installed upstream package itself contains.
The kit-level notices file is `THIRD_PARTY_NOTICES.md` in the kit's top directory, with the verbatim licence and notice texts under
`third_party_licenses/`.
