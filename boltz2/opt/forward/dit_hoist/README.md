# dit_hoist — the CUDA-graph sampler and the step-invariant hoist for the Boltz-2 diffusion module (boltz 2.2.1)

Runtime patches of `AtomDiffusion.sample` and the diffusion module's per-step forwards; nothing in the installed `boltz` package is edited. The kit
stages these files beside the trunk worker and derives the worker it runs with `src/make_worker_variant.py`.

| path | role |
|---|---|
| `src/boltz_graph_patch.py` | `BOLTZ_GRAPH_DIFFUSION=graph`: CUDA-graph capture of the diffusion denoiser step — one capture per (atom, token) shape in a private memory pool, replayed for steps 2…S of every `sample()` (199 replays per 200-step sample); a step that cannot be captured runs the stock step and is counted (`capture_stock_fallbacks`). `BOLTZ_GRAPH_RELEASE_MIN_TOKENS` (1024): below it the graph, its static conditioning clones and the hoist's cache live for the process; from it they are released when `sample()` returns (`release_step_graph`, the hoist's `release_after_sample`) and rebuilt by the next `sample()`, so the confidence module and the next prediction's trunk run with the stock sampler's resident memory (the kept state grows with tokens² × samples: the level-2 cache is 24 × `[B·m, 16, N, N]` fp32 expanded biases — ~32 GB at 2,040 tokens and 5 samples — plus the clones and the pool). Memory-headroom gate (`boltz_dit_hoist.headroom_gate` over `boltz_graph_patch.headroom`, evaluated at every `sample()` before any state is built): the projected working set (`projected_cache_bytes`: `_build_cache`'s terms by shape; `projected_static_bytes`; `step_transient_bytes` twice) plus `BOLTZ_GRAPH_HEADROOM_MARGIN` (0.12) of the card must fit the free memory, else that prediction runs the stock sampler (`_sample_stock_by_headroom`: eager, no hoist, no graph — the arithmetic the graph replays, same output bytes) and is counted `headroom_gated` in both modules' census |
| `src/boltz_dit_hoist.py` | `BOLTZ_DIT_HOIST=2`: everything the denoiser recomputes at every step although it depends only on the trunk outputs / features — the single-conditioning prefix, the fp32 casts of the conditioning tensors, the atom-transformer layers' AdaLN scale / bias and gates conditioned on the step-invariant atom conditioning (level 1), plus the expanded per-layer pair biases and additive mask terms (level 2) — is computed once per `sample()` by the stock sub-modules on the stock inputs in the stock shapes, cached at fixed addresses and read back by the per-step forwards; `STATS["last"]` carries the per-sample counters (cache builds / refreshes / hits, `captured_with_cache`, cache size) the kit reads from the worker log |
| `src/make_worker_variant.py` | derives the worker variant `bz2dit` from a trunk worker (`../trunk_levers/src/bz_worker_lev.py` or `bz_worker_levf2.py`): inserts the import / apply block of the two patches right after the trunk levers (graph patch first, hoist outermost), the sampler timer and the per-item report columns; the kit runs it at every launch (`opt/boltz2_opt/stack.py` `stage`) |

Both patches compute the same arithmetic as the stock sampler: every hoisted tensor is produced by the same module call on the same input as before,
only once instead of once per step, and graph replay re-issues the captured kernels. With their switches unset (the memory mode `big`) the block is
inert and the eager stock sampler runs; `--use_potentials` (per-step steering) takes both off by name for that run.
