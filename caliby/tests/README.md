# Tests

The package's CPU tests (no GPU, no upstream install needed).

## Package tests (CPU)

    pip install -e ../common/opt_core -e 'opt[test]'     # the shared core the package pins, then the package with its test extra (pytest, setuptools), in any venv — a bare `python -m venv` included
    python -m pytest opt/caliby_opt/tests                  # the package suite (one throwaway venv for the packaging test; one short `python -S` child per route × broken core for the core-gate route test)
