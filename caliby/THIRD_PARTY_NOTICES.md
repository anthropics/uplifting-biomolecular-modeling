# Third-party notices — Caliby kit

This kit wraps Caliby 0.1 and two of its upstream dependencies at fixed pins (STOCK.md §Pin). The table lists every third-party component
that files of this kit adapt, restate, wrap or ship: component, upstream location, licence name, the copyright line exactly as printed
upstream, the kit files concerned, and where the verbatim licence text sits. The vendored upstream source archives under `stock/` are
byte-identical to upstream at the pins, carry their own licence files inside, and are never edited. No model weights are distributed with
this kit: `run.sh install --weights DIR` fetches them from their publisher (STOCK.md §Pin; `opt/forward/xattempt_addon/LICENSE_NOTES.md`
§Model weights). Per-directory notices with per-file detail stay where they are: `opt/forward/xattempt_addon/NOTICE`,
`opt/forward/xattempt_addon/LICENSE_NOTES.md`, `opt/forward/fast_inference/NOTICE.md` (provenance of each carried licence text:
`opt/forward/fast_inference/licenses/LICENSE_SOURCES.json`). All kit paths below are relative to this directory (`caliby/`).
The kit's own code is licensed under the Apache License 2.0 (LICENSE in this directory and at the top of the tree); this file concerns the third-party portions only.

Third-party code outside `stock/`, in full. `opt/forward/xattempt_addon/fast/` holds eight modified copies of upstream files and
`opt/forward/xattempt_addon/stock/` the same eight files unmodified (byte-identical to the pinned archives), under one flat name each:
`api.py`, `atom_mpnn_denoiser.py`, `inference_dataloader.py`, `potts.py`, `seq_des_utils.py` (Caliby, Apache-2.0), `complexity.py` (the
Chroma-derived `chroma/layers/complexity.py` inside the Caliby repository, Apache-2.0, header kept) and `protpardelle_core_models.py`,
`protpardelle_data_pdb_io.py` (Protpardelle-1c `src/protpardelle/core/models.py` and `src/protpardelle/data/pdb_io.py`, MIT). Statement of changes
(Apache-2.0 §4(b) for the Apache-licensed six; the same statement is made for the two MIT files): the eight files under `fast/` were modified for
this kit; each marks its modified regions in place (`XATTEMPT` comments), and the complete change of each is the unified diff of the same name under
`opt/forward/xattempt_addon/patches/` (`*.vs_upstream.patch` / `*.vs_protpardelle1c_7962da09.patch` against the upstream file; `*.vs_kit0002.patch` /
`*.vs_kit0003.patch` against the intermediate form that `opt/forward/fast_inference/patches/0002-*.patch` and `0003-*.patch` produce from the upstream
file). The kit modes serve the `fast/` copies by import hook; nothing is written into an installed tree, and the `stock/` copies are what the modes
compare an installed tree against. Apart from these sixteen files, the patch files, the carried licence texts (`opt/forward/xattempt_addon/LICENSE`,
`opt/forward/fast_inference/licenses/*`) and the seven example structures of the last table row, every file outside `stock/` was written for this
kit and contains no third-party code (`opt/forward/xattempt_addon/tests/xcaliby_design.py` restates two CSV-writing lines of Caliby's `seq_des.py`,
marked in place).

Data files. Outside `stock/`: the seven `opt/forward/xattempt_addon/tests/public_inputs/*.cif` files only (last table row: wwPDB entries and
assemblies generated from wwPDB entries, CC0 1.0, as redistributed in the Caliby repository's `examples/example_data/`). The three carried archives
contain source code, configuration and documentation only — no structures, weights, sequence databases or alignments (the one non-code member is
atomworks' `chembl_transformations.smirks` rule table, part of that BSD-3-Clause package). No model weights are in this tree (STOCK.md §Pin).
