# Third-party notices — `openfold3_ob0` kit

This kit ships stock OpenFold3 0.5.0 unmodified under `stock/` and adds its own code under `opt/`. The table lists every third-party
component that files of this kit vendor, restate or adapt, with the licence, the copyright line exactly as printed in that component's
licence text, the kit files concerned, and where the verbatim licence text is reproduced. The per-directory notices
`opt/forward/fast_inference/NOTICE`, `opt/forward/trunk_kernels/NOTICE` and `opt/forward/offload/NOTICE` stay beside the code they describe.
No model weights are part of the kit or of its images; `./run.sh install --weights DIR` fetches the checkpoint through upstream's own downloader.
