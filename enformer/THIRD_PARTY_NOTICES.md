objects that incorporate third-party header code. Upstream itself is carried verbatim under `stock/` (the PyPI wheel and sdist of

## Data files carried under `stock/`

- `enformer_pytorch/precomputed/tf_gammas.pt` — a member of the wheel and of the sdist under `stock/`, and unpacked at
  `stock/src/enformer_pytorch/precomputed/tf_gammas.pt` (393,841 bytes; digest in `stock/PINS.json`): upstream's table of precomputed
  gamma positional-basis values, which `enformer_pytorch/modeling_enformer.py` loads at import (`TF_GAMMAS`) so that its relative-position
  features match the reference TensorFlow implementation numerically. It is part of the upstream release (MIT, the same `LICENSE`), holds
  numeric constants only — no model weights, no genomic data — and is used unmodified.
- `stock/snapshot/README.md` and `stock/snapshot/config.json` — the model card and the architecture configuration of the Hugging Face
  repository `EleutherAI/enformer-official-rough` at the pinned snapshot (`stock/PINS.json` `weights`), carried verbatim so that the pin
  and the weights' stated terms can be read offline; the card's front matter states `license: cc-by-4.0` (next section). `config.json`
  holds hyper-parameters only; the checkpoint itself (`pytorch_model.bin`) is not in this tree.

No other data file (sequence, genome interval, track or checkpoint) is carried in this kit.

## Model weights (not shipped)

No checkpoint is part of this tree or baked into its images. The weights the README names, Hugging Face repository
`EleutherAI/enformer-official-rough` (snapshot `affe5713ae9017460706a44108289b13c5fee16c`, digest in `stock/PINS.json`), are
downloaded by upstream's own `from_pretrained` at first use. Their model card, carried verbatim as `stock/snapshot/README.md`,
states `license: cc-by-4.0` — Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/ — and
describes them as the official weights released by DeepMind, made available in PyTorch form, citing Avsec et al., "Effective
gene expression prediction from sequence by integrating long-range interactions", Nature Methods 18, 1196–1203 (2021),
https://doi.org/10.1038/s41592-021-01252-x.

Other run-time dependencies (PyTorch, einops, transformers, Triton, the NVIDIA CUDA wheels, …) are installed from their own
distributions under their own licences and are not redistributed in this tree.
