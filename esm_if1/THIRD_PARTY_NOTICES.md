and `tests/` trees, which hold the data files below. `pip install` of the archive installs the `esm` package only; the kit reads none of

## Shared support library

`esm_if1_opt` imports only the gate, manifest, report and mode helpers of the release's support library (`common/opt_core/`) and binds none
of its kernels. The third-party licence and notice files of the kernels that library carries stay beside those kernels under
`common/opt_core/` and are listed in `common/opt_core/THIRD_PARTY_NOTICES.md`; none of them concerns a file of this kit.

## Model weights

`esm_if1_gvp4_t16_142M_UR50.pt` is not part of this tree or of the images built from it: `./run.sh install --weights DIR` fetches it from the
upstream address pinned in `stock/PINS.json` (size and sha256 checked). The upstream repository that distributes it is the MIT-licensed
repository above; upstream asks that users of ESM-IF1 cite Hsu et al. 2022, "Learning inverse folding from millions of predicted structures"
(doi 10.1101/2022.04.10.487779), as printed in the upstream `README.md`.
