## The lever unit tests — `k/test_ef2_*.py` (one GPU box with the pinned stack)

The carried design kit's GPU tests through its pytest-free runner `k/run_tests_nopytest.py` (every `k/test_ef2_*.py`, or the modules named on its
command line), run from a writable copy of `k/` (`cp -r opt/forward/ESMFOLD2_DESIGN_FAST_INFERENCE_KIT_v1/k /tmp/k && cd /tmp/k && python -I run_tests_nopytest.py`;
nothing is written under the tree). Random-initialised modules of the installed fork, no weights: `test_ef2_autograd_kernels.py` (K-D3's rounding vs stock, the
frozen-weight backward, the checkpoint policies and the LN dx-only backward BITWISE, the state guard), `test_ef2_trimul.py` (fused TriMul vs an fp64 reference within the
stock path's error, dX vs stock, padding, cueq_tiles tensor-equal), `test_ef2_fused_ln.py`, `test_ef2_bwd_ckpt.py` (plans; `none` / `ckpt:m` / `block` bitwise),
`test_ef2_stepgraph.py` (pool replay bitwise vs eager, live mask, re-install), `test_ef2_esmc_rope.py` (tensor-equal q/k and dq/dk vs the torch branch),
`test_ef2_lazy_structure.py`, `test_ef2_pairbias_attn.py`, `test_ef2_sampler_graph.py`, `test_ef2_bf16_confidence.py`. Two modules drive
the installed cookbook loop and need the pinned weights (`HF_HOME`): `test_ef2_loop.py` (prep / pppl A/B/A bitwise in one process) and `test_ef2_esmc_overlap.py`.
The run succeeds when it exits 0 with `RESULT passed=N failed=0`, N > 0 (a test skipped for want of a CUDA device counts as failed).
