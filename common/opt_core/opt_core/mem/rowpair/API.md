# opt_core.mem.rowpair — API (row-sharded pair stack, `--mode big --n_gpu P`)

Tensor parallelism for a torch cofold engine's memory mode: the pair representation `z[N, N, C]` is ROW-SHARDED over the P GPUs of one
node from the statement that creates it to the last statement that reads it — input embedding / relative-position features / token bonds,
recycling, the template embedder, the MSA module, the pair stack (Pairformer), the distogram / confidence heads and the diffusion
conditioning all run on this rank's rows `[r0, r1)`; nothing `N × N × C` is ever whole on a rank. REPLICATED BY DESIGN (named in each
module's docstring and in the schedule census): the single representation `s`, per-token features, atom tensors and the diffusion
module's atom attention; the MSA representation `m[S, N, c_m]` is replicated (`m_layout="replicated"`, default) or TOKEN-SHARDED
(`m_layout="token_sharded"`: rank q holds `m[S, r0_q:r1_q, c_m]`) — an explicit argument the adapter passes; the raw MSA / deletion features and an `[N, N]` token-bond matrix may stay on the
HOST (`msa_host`) with only the rows a cycle uses on the device. Every rank runs the engine's own control flow on its rows; engine
sub-modules enter as CALLABLES. This package is MECHANISM (engine-free); a kit's adapter (`<pkg>.big` / `<pkg>.tp`) INSTALLS it.
Importing the package imports nothing heavy.

How a kit installs it, stage by stage: `ADAPTER_GUIDE.md` beside this file.

## The structural n_gpu=1 rule
At `--n_gpu 1` a kit's adapter installs NOTHING: no layout, no PatchSet, no rebinding — the engine's single-GPU big path runs byte for
byte (this is what makes the P=1 equality check hold by construction, not by care). The L2 statements, schedules and drivers enforce it:
`trimul_*`, `rowshard_outer_contract`, `colshard_inner_contract`, `trimul_update_`, `gather_triangle_bias`, `triatt_starting/ending`,
`triatt_update_`, `transition_rows`, `opm_rows`, `opm_rows_budgeted`, `pwa_bias_rows`, `pwa_rows`, `msa_block_sharded`,
`apb_local_queries`, `pairstack.pair_block_ / pair_stack_`, `trunk.init_pair_shard / recycle_shard_ / run_trunk_sharded`,
`template.template_embed_rows`, `heads.logit_rows / sym_logit_rows / embed_rows`, `diffusion.pair_cond_rows / pair_bias_rows /
dit_block_sharded / diffusion_transformer_sharded` and `RowBlockReducer` REFUSE a P=1 / replicated / no-group layout by name. The L1 seams
(`shard_rows`, `unshard_rows`, `all_gather_rows`, `transpose_shard(s)`, `slice_template_inputs_to_rows`, …) are the equality at P=1 (true
statements, kept for symmetric adapter code). A kit that ships a row-block statement (the confidence reducer, the row-blocked heads, the row-blocked OPM
`msa.opm_rows_budgeted` / `transition.opm_rows`) as its OWN single-device memory lever passes `allow_unsharded=True` and names that lever in its line (a different lever from n_gpu). The adapter's
own test asserts "installs nothing at n_gpu=1".

## End-to-end row-sharded forward (where z is born; what crosses ranks; what stays replicated)
| stage | statement on this rank's rows (module) | communication | replicated by design |
|---|---|---|---|
| trunk entry | adapter builds ONE `Layout` per query (`dist.ctx(N, align=chunk)` / `Layout.auto`) once N is known; template pair inputs `[T, N, N, F]` sliced to rows once (`template.slice_template_inputs_to_rows`); raw MSA / token bonds optionally parked on host (`msa_host.park_features`) | rank-0 featurisation + `bcast.broadcast_tensordict`, or every rank featurises and `bcast.sync_tensordict_from_rank0` overwrites in place; replicated inputs proven (`assert_replicated`) | per-token features, `s_input` |
| pair init (z is born) | `trunk.init_pair_shard(layout, rows_fn, like)`: `z_loc[b] = rows_fn(g0, g1)` per chunk-aligned row block — the engine's `linear(s_i) + linear(s_j)` (`outer_sum_rows`), relative-position one-hot of the row slab only (`relpos_onehot_rows`), token-bond rows (`feature_rows`, host-resident allowed) | none | — |
| recycling | `trunk.recycle_shard_(z_loc, zinit, update_fn, layout)`: `z = z_init + linear(LN(z_prev))` in place per row block; `z_init` shard optionally parked on host between cycles (`ShardPark` — a GPU mechanism; a CPU tensor stays resident; call under `torch.no_grad()` at inference); driver `run_trunk_sharded` | none (RNG-stream guard: one small all-gather per cycle) | `s`, `s_init` |
| template embedder | `template.template_embed_rows`: per unique slot `u_t` rows = `linear(LN(z rows)) + embed(feature rows)` (`distogram_rows`, `pair_mask_rows`, `same_or_group_rows`, lazy dummy zeros), the per-slot pair stack as a callable on the `[R, N, c_t]` shard, closing mean / linear on rows | slot de-duplication agreement (2 small collectives); the per-slot pair stack's own (below) | template per-token features, coordinates |
| MSA module | `msa.msa_module_sharded`: OPM output rows `z[b] += OPM(m)[g0:g1]` (`transition.opm_rows` / `msa.opm_rows_budgeted`, contraction over S whole per (i, j)); pair-weighted averaging with the logits of LOCAL query rows (`pwa_bias_rows` + `pwa_rows`: every m-side GEMM at the dense M, softmax over all j per row, `linear_o` on the row-gathered slab); MSA transition replicated or token-sharded (`msa_transition_rows`); the block's pair stack = the pair-block driver | `m_layout=replicated`: one all-gather of the `[S, R, H·c]` weighted-value rows per block (+1 when the MSA transition is token-sharded); `m_layout=token_sharded`: the non-local operand of each statement gathered (OPM `b`, PWA values), the m-update stays on the token shard | `m` under `m_layout=replicated` (`msa_m=replicated|token_sharded` in the census); the MSA subsample draw proven identical (`trunk.guard_replicated`) or drawn once (`msa.draw_replicated`) |
| pair stack (Pairformer / MSA / template / confidence pair blocks) | `pairstack.pair_block_ / pair_stack_`: tri-mult outgoing = ring of just-in-time projected b sub-blocks against the resident A block (`trimul.trimul_update_`, streamed schedule); tri-mult incoming = A and b from zᵀ bands (`ring.transpose_band`); tri-att starting = row-local given the all-gathered `[N, N, H]` bias (`triatt.triatt_update_`, query sub-blocks); tri-att ending = the starting statement on the transposed shard (`ring.transpose_shard` / `_inplace_`) and back; pair transition row-local (`pairstack.transition_update_`); attention-pair-bias of the single track = local query rows + gather of the `s` rows (`transition.apb_local_queries`) | ring p2p of b sub-blocks; banded / whole distributed transposes (p2p, budgeted: all-at-once or peer-streamed); bias all-gather `[N, N, H]`; `s`-row all-gather | `s`; the triangle bias `[N, N, H]` per attention call |
| distogram / PAE / PDE heads | `heads.logit_rows / sym_logit_rows`: logits produced row block by row block (`rows × N × bins` at most); `confidence.RowBlockReducer` consumes them on the fly (pTM / ipTM / per-chain aggregates, `exact` finish) ; per-row outputs to rank 0 (`per_row_outputs_to_rank0`) | `exact` finish: per-context matrices gathered to rank 0; per-row outputs: one gather | rank-0 full matrices the writer needs (PAE/PDE images) |
| confidence head pair input | `heads.embed_rows(fn, z_trunk_shard, layout)`: `z_conf[b] = z_trunk[b] + linear(one_hot(d_ij rows))` per row block (never `[S, N, N, C]`); the trunk shard's PLACEMENT across the stage's passes is `heads.ZTrunkPlan` (per pass: `inplace` — the pair input overwrites the shard's storage at its last use, one sample-equivalent per pass — else `parked` — the shard on (pinned) host, device storage released before the pair input is allocated, rows served block by block, the same storage re-grown on request — else `resident`; placement only, bit-identical); its pair stack = the pair-block driver; `confidence.gather_single_rows` for row-sharded `s` updates | as the pair stack | `s`, atom coordinates; atom-pair statements row-blocked but replicated (`frames.nearest_atoms_rows`, `count_pairs_within`) |
| diffusion conditioning + transformer | `diffusion.pair_cond_rows`: `z_cond` rows built ONCE per roll-out from the trunk shard (+ its transitions); per transformer block `pair_bias_rows` (cached across denoising steps by `PairBiasCache` within a byte budget); `dit_block_sharded`: token queries = local rows, keys/values from the replicated activation, updated rows re-replicated once per block; atom attention reads a diagonal BAND of the sharded conditioned pair (`band_plan`, `pair_band_rows`, `band_lookup`) | one all-gather of the `[R, c]` token rows per transformer block per step; band assembly (all-gather of `N × (2W+1) × c` + ≤ `ROWPAIR_DIFF_BAND_EXTRA_MAX` full rows); noise proven / broadcast (`sync_replicated`) | token activations `a`, `s`; atom tensors and the atom attention; the band `[N, 2W+1, c]`; noise and coordinates (the sampler hook is called identically on every rank) |
| checkpoints | `ckpt.TrunkCheckpointer`: each rank writes its z shard + ITS feature digest, rank 0 the replicated tensors + RNG state + the precision tag, manifest last; resume restores shard + RNG stream only from a tag carrying this rank's digest and this line's precision word (refused by name otherwise) | none in the writer (json fragments polled by rank 0) | — |
| writer | rank 0 writes; per-row outputs via `confidence.per_row_outputs_to_rank0`; pair-shaped outputs the writer needs whole (PAE / PDE / contact matrices, distogram logits) via `dist.gather_rows_to_rank0_host` — pinned host tensor on rank 0, assembled in column blocks, never whole on a device | one `gather` per column block | — |

## Process contract (what an adapter does)
1. CLI: absent `--n_gpu` ≡ `--n_gpu 1`; `P = rowpair.refuse_unless_big(args.n_gpu, args.mode)`; the ACTIVE line gains `*evidence.fields(P)`.
2. `P == 1`: the kit runs exactly what it runs today (the adapter installs nothing). `P > 1`: `result = launch.run_sharded(P, kit_entry,
   request, mode=args.mode, run_timeout_s=<the kit's watchdog budget>)` — `kit_entry` runs the engine's predict for one request on one rank;
   inside it the adapter sets `ROWPAIR_CHUNK_ALIGN` to the engine's pinned chunk size, builds ONE layout per query at TRUNK ENTRY once N is
   known (`dist.ctx(N, align)` or `Layout.auto(N, P, rank)`), slices the `[T, N, N, F]` template inputs to rows, parks the raw MSA on the
   host if configured, and runs the trunk through `trunk.run_trunk_sharded` with the engine's sub-modules bound as callables (template →
   `template.template_embed_rows`, MSA → `msa.msa_module_sharded`, pair stack → `pairstack.pair_stack_`), then the heads / confidence /
   diffusion statements on the shard (ADAPTER GUIDE, stage table); it writes files only when `launch.is_output_rank()`.
3. LEVER lines: `evidence.emit_rank0(evidence.lever_line(TAG, "on", P, layout=lay, peaks_gib=evidence.gather_peaks(), **dict(evidence.rows_census(lay))))`
   once per process — it carries `strategy=<canonical id> n_gpu=P sharding=rowpair`, the layout facts, per-rank peaks, the rows census and
   the schedule census (every block size and its source, every replicated-by-design word). ONE activation line per arm per process.
4. EXIT line (parent): `*evidence.fields(P)` + `*evidence.peak_fields(result["peaks"])` + `ranks_ok=k/P` from `launch.last_run()`.
5. `launch.RankFailed` → `emit(evidence.rank_failed_line(TAG, exc))`, exit non-zero. `RowpairRefused` / `NGpuRefused` → the kit's refusal
   path (message = `exc.reason`, rc ≠ 0).

## Accepted (N, P) domain
Grid policy `Layout(N, P, rank, B)`: `nb = ceil(N/B)` blocks dealt `bpr = ceil(nb/P)` per rank; valid for a sharded run iff `N ≥ P·B` and
every rank owns ≥ 1 row (`nb > (P−1)·bpr`); `Layout.auto` picks the largest B ∈ {128, 64, 32, 16} (∩ multiples of the engine's chunk size)
that is valid: every memory-ladder bin {1000 … 16000} × P ∈ {2, 4, 8} has a plan; shapes with no plan are refused by name listing the
candidates tried. Aligned policy `Layout(N, P, rank, align=k)` / `dist.ctx(N, k)`: `dist.row_parts(N, P, k)` — balanced, every boundary a
multiple of k, the last rank ragged; refused by name when a rank would own no rows (`N < (P−1)·k + 1`).

## Numerics classes (reduction-order table)
| primitive | communication | order of sums vs dense | class at fixed P |
|---|---|---|---|
| shard / unshard / transposes / ring passes / bias gather / bcast / band assembly / host parking | all-gather, all-to-all, isend/irecv, broadcast, D2H/H2D copies | none (data movement) | bit-exact |
| pair init rows, recycling, pair transition, LayerNorm, residual adds, OPM output rows, template u rows and closing mean/linear, head logits rows, confidence embed rows, diffusion conditioning / bias rows, masks | none | unchanged per element; launch M = local rows | bit-exact iff kernels are M-invariant (CPU fp32: yes; engine stacks: tested per engine) |
| trimul streamed schedule / contraction primitives | ring of b sub-blocks / zᵀ bands / all-to-all windows | full k inside ONE matmul per tile; tile extents (and boundary-block J) differ from the dense call | bit-exact iff the batched GEMM is tile-extent invariant (no split-K); else ≤ stated tol |
| triatt starting / ending, PWA softmax, diffusion-transformer attention | bias all-gather (+ transposes for ending); row gathers | softmax + PV whole per query row | bit-exact iff the kernel is query-count invariant |
| fused triangle kernels on row blocks (`trimul_fused` K1/K3 through the streamed schedule; `attention_core` flash / cuEq per row block) | as the two rows above (no new communication) | the fused single-GPU kernels' rounding points (bf16 LN output / gated planes / contraction operands / LN_out / gated output, fp32 accumulators; online softmax in fp32) on the sharded schedule's blocks and tiles | tolerance class (Tier 2) vs the torch statements and vs the single-GPU fused kernel; run-to-run repeatable (fixed cells, no atomics, no split-K); never claims bit-exactness |
| attention-pair-bias (local queries) | all-gather of output rows | whole per query | as above |
| replication guards (checksums), slot de-duplication agreement, Philox rejection-round agreement (`rng`) | all-gather / max-allreduce of integers | none | exact |
| rows of pair-shaped CUDA Philox draws (`rng.trunc_normal_rows`, `dropout_rows`) | none (one int64 allreduce for the round count) | the stock kernel at the stock launch geometry and generator offset | bit-exact vs the stock full-tensor draw (CUDA); refused on CPU |
| heads (row blocks / column slabs) | all-to-all windows (transpose term) | none: per-(i, j) maps; the exchange is data movement | bit-exact iff fn's kernels are M-invariant (CPU fp32: bit-exact) |
| confidence reducer `exact` (`ContextReducer` block | sub form) | gather of per-context matrices to rank 0 | same products, same inner sum over bins on different outer shapes | bit-exact iff the inner reduction is outer-shape invariant (CPU fp32: bit-exact) |
| `FastContextReducer` vs `ContextReducer` (either form) | packed column gathers (block) / the per-context statement on same-shape tensors (sub); batched gathers | copies of the same elements; identical statements | bit-exact by construction on every device (asserted: `tests/test_rowpair_confidence_fast_05213.py`, P ∈ {2, 3}, both forms) |
| confidence reducer `rowsum` | gather of O(N) scalars | REORDERED | tolerance (|diff| ~ 1e-7 fp32), never bit-exact |
| atom-pair row blocks (`frames`) | none | top-k / count per row on identical rows | indices bit-exact; counts exact |
Budget-derived block schedules (`*_source=budget`) derive from `dist.agreed_free_bytes` (identical on every rank, so every rank walks one
schedule) but vary machine to machine, so even at fixed P two draws are a BAND unless the blocks are pinned; the schedule is printed in every LEVER
line. Mode rule that follows: `n_gpu>1` is big-only (tier-2 numerics, tested as a band with n ≥ 2 draws; never claims exact).

### structure_first — `capture(pl_module, batch, is_writer)`, `write_early(batch, x, sample0, write_structure, log=, enabled=, switch=)`, `mark_final(batch, outputs=, log=)`, `scan(out_dir)`, `words()`, `reset()`, `utc()`, `SIDE_SUFFIX`, `WRITE_WARN_S`
Rank 0 writes each sample's model file through the engine's static writer right after the sampler (pLDDT column 0.00 + `<prefix>_structure_first.json` sidecar); the engine's unchanged writer overwrites it after the heads; `mark_final` flips the sidecar only on an actual rewrite; `scan` gives the run record its block and the structure-only paths the binding's exit tally does not count. `heads.pinned_shrink(say, plan=)` is the confidence-pairformer -> heads seam operation (release the A-block row mirror + trim torch's cached-free pinned blocks; `ROWPAIR_POOL_SHRINK=0` off; under `ROWPAIR_HOST_SLAB=lease` it also returns a FREE leased slab, census `pool_shrink_slab_gib`).

### Host parks 1× — the adapter binding
Constants of a tp line (kit `tp_rowpair/env.py LINE_CONSTANTS`): `ROWPAIR_HOST_SLAB=lease`, `ROWPAIR_PARK_ZINIT=recompute` (was `1`). ONE call site: in the confidence adapter, between the pass's `embed_rows` (the `[k, R, N, C]` pair input exists) and that pass's pairformer stack, call `plan.retire(i)` on the roll-out's `ZTrunkPlan` (OB0/OF3: `tp_rowpair/confidence.py pairformer_embedding_rows` right after `zc = HD.embed_rows(...)`, reached from `aux_heads_rows` through an `after_embed` callable; a one-pass plan built inside `aux_heads_rows` likewise). `retire` is a no-op by word on non-last passes and for `inplace`/`resident` forms; `plan.end(i)` stays where it is (it then only closes). Nothing else moves: the row mirror's per-call lease/release and the parks' slab hand-over are inside the core. Expected pinned host per rank: 1 u in the trunk (all cycles), the sampler, the last confidence pass and the heads (0 u after the seam shrink); 2 u (named `host_slab_second=ParkedStorage:z_trunk.confidence+trimul_row_mirror`) only inside a NON-last pass's confidence pairformer when the A-block schedule is multi-pass there.
