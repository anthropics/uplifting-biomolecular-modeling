# Third-party notices — `opt_core` (`common/opt_core`)

`opt_core` is original work released under the licence in `common/opt_core/LICENSE`. Parts of it restate, adapt or
extend the arithmetic of third-party model code, two header files carry trimmed third-party source, and several of its
prebuilt GPU binaries were compiled against third-party headers (some contain object code instantiated from those
headers' templates, four link the CUDA runtime statically). This file lists those components, where they appear in this
package, which binaries contain them, and where the full licence texts are carried (`common/opt_core/third_party_licenses/` unless a path inside the package is given). No file listed
under "files in opt_core" is a copy of an upstream file unless the row says so; per-directory `NOTICE` files give the
details for each kernel package.
